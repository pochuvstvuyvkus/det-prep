# Курс на 160

Неофициальный тренажёр Duolingo English Test. Не связан с Duolingo и не одобрен им.

- 13 типов заданий теста с таймерами как на экзамене
- 12 вариантов без повторяющихся заданий, каждый день — новый вариант
- чтение и аудирование проверяются сразу, с разбором ошибок
- тексты и устные ответы сохраняются в файл для проверки по критериям теста
- гид: формат теста, шкала 10–160, критерии, как отвечать на каждое задание

Все задания написаны для этого тренажёра. Формат, время и критерии взяты из открытых материалов Duolingo English Test 2026 года. Фотографии — Unsplash, загружаются с picsum.photos.

## Запуск на своём компьютере

```bash
python3 -m http.server 8790
```

Затем откройте http://localhost:8790

## Устройство

Статический сайт без сборки: `index.html`, `css/`, `js/`, банки заданий в `data/`.
Озвучка и распознавание речи — встроенные в браузер (Chrome, Safari); ничего не отправляется на сервер.
